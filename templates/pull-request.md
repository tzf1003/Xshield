# PR 交付清单

## 变更目标与追踪
关联 RQ、INV、ADR、验收用例；列出新增/变更原因码、Schema 版本、站点范围。

## 实现边界
写明所属领域和 port；是否新增跨层依赖、资源上限、超时/取消、事务/幂等语义。权限范围扩大必须单独审批。

## 审计与秘密
每个 PASS/DENY/UNKNOWN/ERROR/SKIPPED 分支如何记录？实际模型/工具输入输出如何关联？哪些字段排除，fidelity 如何变化？确认 Debug/tracing 不泄漏原始秘密。

## 测试与证据
提供单测、契约、并发/故障、安全反例、性能结果；分别标明已执行和未执行。不要用格式化通过代替业务验证。

## 发布与回滚
迁移兼容性、灰度范围、监控指标、回滚触发和旧数据处理。新规则不能由客户端选择降级。
