# 00 产品定位与需求基线

版本：3.0｜基线日期：2026-09-17｜状态：设计规格，尚非实现或实测报告。

## 0.1 最终定义

Xshield 是以前置反向代理为部署形态、以 Rust 为主要实现语言的上下文增强 WAF。它结合自动注入的 JS 探针、可选的站点加密协议接管、业务认证强绑定、界面操作来源图、资源操作资格账本、确定性检查、Jev/OpenJev 语义判别及全链路审计。

核心目标不是推断源站隐藏的全部 ACL，而是执行站点明确接受的附加准入规则：**除批准的入口外，没有当前认证上下文中的可追溯界面操作依据，就不执行受保护请求；即使该用户在源站实际拥有权限，也不例外。**

“可追溯”指来源、映射、目标与约束可由 WAF 验证，不表示证明用户亲手点击过按钮。真实浏览器、在线心跳和客户端堆栈不能自行授予资格。

## 0.2 已确定的产品约束

| 编号 | 约束 | 落地含义 |
|---|---|---|
| RQ-01 | 项目名 Xshield，Rust 主语言 | 网关、策略、账本、审计、控制 API、任务编排用 Rust |
| RQ-02 | 不要求接入业务 SDK | 自动注入普通 JS；按站适配；源站改造不是首版前提 |
| RQ-03 | 接管双向流量 | 请求和响应均有独立检查、转换及覆盖状态 |
| RQ-04 | 前端心跳与操作关联 | WSS/HTTPS、页面实例、动作和请求 ID，不以最新心跳代替因果 |
| RQ-05 | 可接管应用层加密 | 原协议解密、密钥封装接管或请求封装 Hook；检查与实际转发内容一致 |
| RQ-06 | 允许受控兼容回退 | 由服务端选择范围；不能因客户端故障声明自动放宽 |
| RQ-07 | 无资格默认拒绝 | 换浏览器、未查询的新资源必须重新走认可入口 |
| RQ-08 | 资格有有效期 | 一天是会话最长租期示例；有效期内已有资格可复用 |
| RQ-09 | 业务凭证强绑定 | WAF Cookie、实际 Session/JWT、身份代际、资格账本绑定 |
| RQ-10 | 认证更新区分性质 | 合法续期可保留相同权限上下文；换账号隔离；未知替换拒绝 |
| RQ-11 | 操作而非 ID 授权 | 评论作者 ID 不发行密码重置资格；读写、字段、视图分离 |
| RQ-12 | 界面来源作为强制前提 | 无相关入口拒绝；Jev 匹配候选，不凭自由输出发明权限 |
| RQ-13 | 明确例外入口 | 公开、认证、分享、服务身份等独立策略，全部仍受审计 |
| RQ-14 | AI 持续适配 | 监测版本，分析候选，独立测试，灰度与签名发布 |
| RQ-15 | 每个请求可审计 | 接收、各层结果、最终动作、响应、失败与跳过原因 |
| RQ-16 | 模型及 Agent 完整调用证据 | 实际逻辑输入、输出、工具调用、版本、用量、证据来源 |
| RQ-17 | 解密和转换证据 | 原始实体、解密/标准化版本、重建请求、响应转换可关联 |
| RQ-18 | ID 快速调查 | 请求、追踪、事件、资格、证据、模型调用、Agent 运行均可查 |
| RQ-19 | 可维护的分层代码 | 领域纯逻辑、端口、应用编排、适配器、入口单向依赖 |
| RQ-20 | 注释、日志与测试为交付要求 | 新增安全分支必须带原因码、结构化审计和测试 |

## 0.3 首版覆盖

首版选择一个测试站点，覆盖认证、列表、详情、创建、资料修改、管理员密码重置、评论、分享，以及一组双向加密 API。支持有界 HTTP/1.1、HTTP/2 请求响应与探针 WSS；业务 WebSocket 每消息授权、任意流式响应、任意 WASM 加密、HTTP/3 为单独适配项，不宣称自动继承覆盖。

新接入先 observe 验证，再 enforce；产品目标为强制模式。compatibility 仅是明确登记的局部豁免，不改变认证绑定、已知资格和审计要求。客户端删 Cookie、改版本、禁用 JS 都不能选择模式。

## 0.4 成功标准与不做的承诺

成功标准：无来源请求在进入源站前被拒绝；实际内容检查可重建；A/B 凭证串用被拒绝；每个处理阶段有可检索证据；协议更新不会静默扩大资格；故障行为有可测试定义。

不承诺：永久无人绕过、通用自动解密、模型概率等于正确率、完整凭证盗用免疫、无源站配合的数据库事务级撤权或 exactly-once。源站通过正常受认可界面错误暴露了高权限功能时，仅靠流程存在无法发现全部业务授权缺陷；控制台必须显示这是流程准入，不是完整 ACL 认证。[S01][S02]

## 0.5 文档优先级

本 v3 基线覆盖此前 v1 的“默认后端 Guard/业务 SDK”和 v2 的“直接访问兼容恢复优先”等建议。最新版用户选择是首要产品约束。源站 Guard 可作为未来插件，但首版不依赖它。禁止用旧示例默认 120 秒资源 TTL 覆盖本版可配置的一天会话租期；资源和操作可有更短 TTL。
